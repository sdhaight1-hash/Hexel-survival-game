# V5.9 — Direct rock palette families (no primary color)

This is a deliberately isolated replacement of V5.8's color path.
The V5.7 geological shape generators, V5.4 world-space structural overlays,
gallery layout, and V5.5 14cm edge strips remain in place.

## Model

- Each granite/shale/basalt hexel deterministically receives one of five
  **full palette families** for its rock type, based on axial coordinates.
- Each of the fifteen families contains **four actual RGB colors**, not
  one RGB parent tint and not four near-neutral multipliers.
- The geological structure already generated by V5.7 chooses and blends
  the four colors: interlocking mineral IDs + grain for granite,
  bedding + fine lamination for shale, dark vesicles + groundmass
  for basalt. No new procedural 3D-noise evaluations are added.
- **Only adjacent solid hexels in the same gallery pad** contribute
  neighboring family weights, over the existing ~14cm edge strip.
  The GPU samples the full family-generated rock color for each
  contributor and blends the **final colors**, not their parent tints.
  Air boundaries do not borrow any family.
- A pads (01/05/09) remain true grayscale-only controls. B/C/D
  use the complete family palette. F5 raw IDs still show each hexel's
  deterministic family; F5 blend mode now displays the actual five
  family weights with diagnostic primary colors.
- The gray geology intensity still subtly changes output brightness
  and carries the existing C/D geological shading. It does **not**
  provide a primary RGB color for tinted pads.
- No bump/height-based normal perturbation is present.

## Implementation boundary

Only gallery-specific family weight computation, mesh vertex attributes,
fragment palette selection, and one legacy test contract were changed.
Non-gallery terrain remains on its original texture/vertex-color path.
No terrain world generation, save format, canonical torus geology,
or P0 materials were modified.

The V5.5 gallery already subdivides exposed faces to carry blend strips.
V5.9 reuses those vertices and stores five interpolation weights
(4+1 floats) instead of a single per-hexel RGB tint and unused
V5.6 seed/mask. That slightly increases the mesh vertex stride.
The current expensive V5.7 granite and basalt cellular scans are
unchanged and still need performance optimization before production.

## Visual acceptance

F5: **normal materials**. F6 UV checker: **off**.

1. A (01/05/09) stays gray and resembles V5.7's base.
2. B (02/06/10) displays obvious related-color *variation inside a
   single hexel*, following granite grains, shale strata, basalt
   groundmass and pores. There is **no uniform parent tint** to apply.
3. C/D retain the existing world-space geological detail.
4. F5 raw ID should show five flat family IDs. F5 blend view should
   show the first family strongly in a cell's interior, and multiple
   diagnostic colors in narrow shared-solid edge strips.
5. Check seams, exterior air boundaries, top/side transitions,
   and whether mineral colors look cartoonish or oversaturated.

Failure modes: if colors still look like flat patches, inspect the
rendered family selection rather than increasing general noise.
If seams are obvious, inspect neighbor weights and shared-feature
alignment. If motion stutters, investigate the existing cellular
substrate expense before further expanding procedural materials.

The branch was checked for intended source wiring, but native Cargo,
Naga semantic validation and RTX 2060 runtime have not been executed
in the authoring environment.
